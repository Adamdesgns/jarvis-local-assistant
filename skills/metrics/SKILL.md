# Metrics

One pull, all the numbers that matter on this machine:

- Tasks: open, overdue, completed today
- Memory: saved notes JARVIS can recall
- Vault: raw captures, wiki notes, shipped outputs, wikilink count
- System: uptime and memory in use

The pull is spoken out loud and the full report is written to
`vault/outputs/` as markdown, so every day's numbers stay comparable.
