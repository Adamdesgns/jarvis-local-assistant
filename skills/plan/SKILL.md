# Plan Today

Picks today's top 3 from the task list — overdue work first, then
anything due today, then the newest open tasks — and writes them as a
checklist under a "Plan" section in today's daily note in
`vault/raw/daily/`. Spoken out loud so the day starts with a decision,
not a scroll.
