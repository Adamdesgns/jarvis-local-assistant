Blink cameras finally play live. Blink used to be snapshots-only in JARVIS — now you can watch them live, with nothing saved to disk, and battery cameras are always released the moment you stop watching. Signing in to Blink works again too: Amazon retired the old login, so JARVIS now uses Blink's own sign-in page — it never sees your password, and the emailed-PIN step is gone. Ring live view is also fixed (it never actually worked on real hardware before this). Each camera gets its own pop-out window and a per-camera hide switch.

Also new: the ULTRON orb skin, every orb now moves with JARVIS's voice (including the floating widget), a cinematic finishing pass on every skin, and two orb performance fixes. JARVIS now opens full screen until you minimize it.

Installing this version also fixes Windows "Installed apps" showing the wrong version number for JARVIS.
