06

Eyes & hands

He can see your screen when you ask, and — in beta — click and type for you. Both were built rails-first: the indicator, the plan card, and the STOP window existed before the first real action did.

  • “Look at my screen” — captures and describes your screen with the cloud vision model, always behind a red on-screen indicator, logged to Activity with a live timeline. Refuses plainly when no key is set. Shipped
  • Screen driving — “click Save”, “type hello world into Notepad”, “select budget.xlsx in Explorer.” File Explorer and Notepad first; Chrome later behind its own clean profile. Beta
  • You see the plan first — every job shows a numbered plan card and waits for your OK; steps that save, send, delete, or overwrite pause again individually mid-job.
  • A STOP window stays on top the entire time, showing the current step in plain English. Press it, hit Escape, or say “stop” — everything ends instantly, with a chime at start and end.
  • Named buttons, never blind clicks — controls are pressed by their accessibility name through Windows UI Automation. If a control is missing or ambiguous, he stops and asks. He never guesses at coordinates.
  • Honest logging — every press is logged; anything typed is recorded as a hash and a length, never the text.

Hard walls, enforced in code and re-checked before every single press: financial windows — banks, brokers, anything that spends — are blocked permanently with no off switch, not even by voice. Sign-in surfaces refused. Password fields never typed into. A Windows UAC prompt ends the job and hands you the machine. Never runs unattended, on a schedule, or from the phone.

The safety core

Every capability above sits on the same bedrock. These aren't settings — they're how the thing is built.

  • It cannot send messages, spend money, or run shell commands — by architecture, not policy. The model is never handed a command line.
  • Destructive actions ask first — deletes (Recycle Bin only), moves, renames, and shutdown all show an approval card.
  • Approved folders are a wall, enforced in the Electron main process — a rule you tell a model is not a control, so the control doesn't live in the model.
  • All your data lives in one folder (%APPDATA%\jarvis-local-assistant) you can back up, export, or delete outright.
  • No account. No telemetry. No subscription. The app checks GitHub for new releases and tells you — nothing ever installs itself.
  • Honest distribution — it's a free, unsigned app, so Windows SmartScreen will warn you; every release ships with a SHA-256 checksum you can verify.
